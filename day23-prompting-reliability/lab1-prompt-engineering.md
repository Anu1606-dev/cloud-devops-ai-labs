# Day 23 - Lab 1: Prompt Engineering

## Objective
Understand how prompt quality affects AI responses.

## Experiment 1 - Weak Prompt

Explain HTTP 502.

## Experiment 2 - Improved Prompt

Role:
Act as a Cloud Support Engineer.

Context:
A web application is returning HTTP 502 Bad Gateway.

Task:
Explain the likely causes and provide a troubleshooting procedure.

Constraints:
- Do not assume the root cause.
- Start with non-destructive checks.
- Explain each command.
- Keep the explanation beginner-friendly.

Output:
1. Meaning of HTTP 502
2. Five possible causes
3. Troubleshooting commands in order
4. Expected results
5. Interview-ready answer

## Conclusion
A structured prompt provides context, instructions,
constraints and an expected response format.
