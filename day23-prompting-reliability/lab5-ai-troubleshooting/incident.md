# Day 23 - Lab 5
# AI Cloud Support Incident Simulation

## Incident

A production Node.js API is returning intermittent HTTP 503 errors.

The service was working earlier.
The root cause is unknown.

## Environment

- OS: Linux
- Application: Node.js API
- Server: Cloud-hosted VM
- Error: HTTP 503 Service Unavailable

## Constraints

- Do not assume the root cause.
- Do not invent logs or system output.
- Begin with read-only diagnostic commands.
- Do not recommend destructive actions.
- Explain every diagnostic command.
- Return the final response as valid JSON.

## Objective

Generate a structured troubleshooting plan
for investigating the HTTP 503 incident.
