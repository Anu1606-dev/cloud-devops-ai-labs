## Hands-on approach

- Linux commands and troubleshooting exercises
- Git and GitHub workflows
- AWS architecture and configuration exercises
- JSON policy and infrastructure design practice
- Node.js and serverless simulations
- Monitoring, metrics, logs, and cost-analysis scripts

## Important note

Some exercises use local simulations and configuration files rather than
deploying live AWS resources. AWS architecture and policy files are learning
artifacts, not proof of deployment to an AWS account.
